# Z-DON Skins

English | [繁體中文](README.zh-TW.md)

Skins made for [Z-DON](https://github.com/GanYiZhong/Z-DON), the AI-developed fork of
[YataiDON](https://github.com/Yonokid/YataiDON). Each comes in two builds: one for Z-DON and one for upstream
YataiDON. Both are **standalone**: copy the folder into `Skins/` and pick it in the settings; no other skin needs
to be installed.

| Skin | Look |
|---|---|
| **YataiDONSimpleStyle** | A light, 8-bit look: a cream screen under a pale sky, a festival stage, white windows with an ink border, two original pixel characters (Momo the rabbit and Hoshi the husky pup) |
| **YataiDONSimpleStyleDark** | The same skin at night: dark windows, light text and a starry sky. It is a child of YataiDONSimpleStyle, so install both |

## Which folder to use

| Folder | For | Resolution |
|---|---|---|
| [`Z-DON/`](Z-DON) | Z-DON | 4K: pictures at twice the size (`screen.texture_density = 2`), font overlays per language |
| [`YataiDON/`](YataiDON) | upstream YataiDON (and other engines without those two features) | 1080p, one font with every language |

The two builds have the same layouts, art and scripts. Features only Z-DON has (hit timing panel, song progress,
chart stats and recent plays on the song select, section loop in practice, Z-DON's AI battle, the extra Z-DON
settings) are simply not shown on upstream: the scripts check that the engine has them first. Checked on upstream
YataiDON `602ed8d` (title, entry, song select, dan select, settings, a full auto play to the result, practice):
everything draws and no script error is logged. One thing differs: upstream draws the Japanese version of the
pictures that have text baked in (for example the settings header), because it doesn't pick `name_<language>`
pictures by itself.

## Installing

1. Download the latest zip from [Releases](https://github.com/GanYiZhong/Z-DON-Skins/releases/latest):
   [`Z-DON-Skins-Z-DON.zip`](https://github.com/GanYiZhong/Z-DON-Skins/releases/latest/download/Z-DON-Skins-Z-DON.zip)
   or [`Z-DON-Skins-YataiDON.zip`](https://github.com/GanYiZhong/Z-DON-Skins/releases/latest/download/Z-DON-Skins-YataiDON.zip).
   It is rebuilt on every update of `main` (rolling release). Or download / clone this repository.
2. Copy `YataiDONSimpleStyle` (and `YataiDONSimpleStyleDark` if you want the dark one) from the zip (or
   this repository's `Z-DON/` or `YataiDON/`) into your game's `Skins/` folder.
3. Choose the skin in the game's settings.

The Z-DON install zip already contains the Z-DON build of both.

## What `_base/` is

YataiDONSimpleStyle is built on the layouts and screen flow of **YataiDONNijiiro**, which builds on
**PyTaikoGreen**. To make it standalone, the files it still uses from those two skins are copied into
`YataiDONSimpleStyle/_base/` (its `skin_config.json` names `YataiDONSimpleStyle/_base/YataiDONNijiiro` as the
parent), so the engine finds them exactly as it would in the original skins. Only what the skin actually uses is
copied; the parents' background system, 3D character models and the art of modes SimpleStyle doesn't draw (the
upstream AI battle, わいわい, campaigns, the reward shop, gacha, tournaments) are left out. These files belong to
the authors of YataiDONNijiiro and PyTaikoGreen.

## Rebuilding

- [`generator/`](generator): the Python generator that draws every SimpleStyle texture and writes its scripts
  (`python build.py`; `--theme dark` for the dark palette, `--density 1` for a 1080p build). It reads the parent
  skins from `SS_SKINS` (a `Skins` folder with YataiDONNijiiro and PyTaikoGreen). See its guides
  (`SCREEN_GUIDE_V2.md`, `STYLE_GUIDE.md`, `README_dark.md`).
- [`tools/zdon_standalone_skin.py`](tools/zdon_standalone_skin.py): copies a skin with the parts of its parents
  it uses nested in `_base/`.
- [`tools/zdon_skin_upstream.py`](tools/zdon_skin_upstream.py): turns the Z-DON build into the upstream one
  (halves the skin's own pictures and texture.json numbers, keeps only the base font).

```bash
python tools/zdon_standalone_skin.py <Z-DON>/build/bin/Skins YataiDONSimpleStyle Z-DON --exclude 'Models/*' ...
python tools/zdon_skin_upstream.py Z-DON/YataiDONSimpleStyle YataiDON/YataiDONSimpleStyle
```

The exact exclude list is in Z-DON's `tools/zdon_bundle_simplestyle.sh`.
