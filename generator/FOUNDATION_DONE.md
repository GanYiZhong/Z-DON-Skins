# SimpleStyle phase 2: foundation done (2026-10-28)

Read `SCREEN_GUIDE.md` first (module contract, captures, rules), then `STYLE_GUIDE.md` (tokens, scale, motion).

## Done
- **Generator split into modules** (`build.py` MODULES = core, game, song_select). Each module declares the paths it `OWNS`, and `--only a,b` rebuilds just those. `skin_config.json` is always reassembled from all modules' fragments.
- **Tokens:** `ss/tokens.py` has three layers (primitive → semantic → component). The contrast check runs on every build and fails it below 4.5 (text) or 3.0 (large / ui). `python -m ss.tokens` prints the table. `STYLE_GUIDE.md` token tables regenerate on every build. All 36 pairs pass.
- **Fonts** (OFL, `Fonts/OFL.txt`):
  - font.ttf = Noto Sans JP 700
  - font_tw = Noto Sans TC 700
  - font_cn = Noto Sans SC Regular (CFF→TTF; no Bold SC on this machine)
  - font_kr = Noto Sans KR Bold (CFF→TTF)
- **Mascot:**
  - Three concepts are on `mockups/mascot_concepts.png`; A "Tick" (metronome robot) is chosen, and `--mascot B|C` switches.
  - Textures are `global/ss_mascot`.
  - The Lua `UI.Mascot` (`Scripts/global/ss_ui.lua`) has 8 expressions, a beat squash and a pendulum swing.
- **Gameplay:**
  - The mascot is in the top band and reacts to good hits, combo 100s, miss streaks, GOGO, clear/FC and fail.
  - The decorative rings are removed.
  - **1P info panel:** title/subtitle, course+★level (when chosen in song select), live BPM, soul %, 良/可/不可/連打, max combo, accuracy with a bar, and average timing (only if `show_timing_offset` is on).
  - The panel is hidden on 2P, dan, practice and AI.
  - The score popup no longer garbles (one popup at a time; the counter catches up).
  - The GOGO title / "1曲目" overlap is the engine's crossfade (song_info.cpp anim 3), so it is left alone.
- **Song select:** Lua patches record the chosen course/level for the info panel (`SS_COURSE_BY_PLAYER`).
- **Capture tooling:**
  - `run_cap.sh` scenarios: title, entry, song_select, diff_select, dan_select, settings, practice_select, practice, dense, roll, result.
  - `tools/mk_testdir.sh` makes private test installs; `test_ss_green` (PyTaikoGreen) is for comparison.
  - Green reference captures are in `caps/green/`.
- **Test config** (test_ss only): language = ja, show_timing_offset = true.
